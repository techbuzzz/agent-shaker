## ❌ Найденные ошибки и проблемы

### 🔴 Критические (требуют исправления)

#### 1. `create_milestone` - только для PM
**Ошибка:**
```
Forbidden: tool "create_milestone" is PM-only.
Connect with an agent whose role='pm' or ask the project owner
to grant your agent the PM role.
```
**Проблема:** Агент с ролью `backend` не может создавать вехи (milestones)
**Решение:**
- Добавить возможность запроса на повышение прав
- Или создать PM-агента для тестирования

#### 2. `publish_global_context` - только для PM
**Ошибка:** Аналогично `create_milestone`
**Решение:** Требуется роль PM

---

### 🟡 Средние (улучшения)

#### 3. `create_task` - обязательное поле `title`
**Ошибка:** При попытке создать задачу без `title`:
```
{"error": "title is required"}
```
**Проблема:** Вызов прошёл валидацию схемы, но сервер вернул ошибку
**Решение:** Добавить валидацию на уровне MCP клиента

#### 4. Несогласованность форматов ответов
**Проблема:**
- `list_tasks` для пустого проекта возвращает `null`
- `list_contexts` возвращает `{ "contexts": null, "count": 0, "note": "..." }`
- `list_milestones` возвращает `{ "count": 0, "milestones": null }`

**Решение:** Унифицировать формат - всегда возвращать объект с массивом

---

### 🟢 Низкие (косметические)

#### 5. Отсутствие документации по правам доступа
**Проблема:** Не указано заранее, какие функции требуют роль PM
**Решение:** Добавить метаданные о требуемых ролях в описание инструментов

#### 6. Heartbeat metadata не валидируется
**Проблема:** Можно передать любые данные в `metadata`
**Решение:** Добавить схему валидации для metadata
